# AURA INK LAB — Website starter

Responsive bilingual (English / Simplified Chinese) static website concept.

## Preview locally
Open `index.html` in a browser. For a local server, run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Before publishing
1. Replace concept tattoo/studio images in `assets/` with the studio's own authorized photographs.
2. Add the correct WhatsApp business number in `script.js` (`WHATSAPP_NUMBER`), international format without `+` or spaces.
3. Confirm the final studio address, opening hours, artist biography, social links, booking/deposit rules, and hygiene/sterilisation wording.
4. Review all prices and terms before publishing.
5. Connect a domain and deploy the folder to a static host such as Vercel or Netlify.

## Notes
- The portfolio and studio photographs included are generated visual concepts, not proof of completed client work or actual premises.
- This starter does not yet include a database, online payment, appointment calendar, or admin dashboard.
